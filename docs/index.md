# World Battery Hub — Data

Machine-readable battery data for lead-acid and lithium batteries. This is the data sub-site of
[World Battery Hub](https://worldbatteryhub.com) — the companion to the knowledge articles, carrying
the structured specifications, reference tables and cross-references.

## What lives here

| Asset | Description | Status |
|---|---|---|
| [CCA Reference](/cca/) | Cold Cranking Amps by standard (JIS / SAE / EN / DIN) | Live |
| Battery groups | H4–H9, L1–L6, JIS, BCI group cross-references | Coming |
| Battery database | Lead-acid and lithium model specifications | Coming |

## How data is handled

- Every quantitative value states its **test standard** — a CCA number without its standard is not recorded.
- Sources are **public and cross-verified**; conflicts are flagged, not silently resolved.
- This is informational data, not purchasing advice.
